
# Emotion Tune – Music Recommendation with Emotion Recognition

## Project Overview
Emotion Tune is an AI-based music recommendation application that detects human emotions through facial expressions using a webcam and recommends music based on the detected emotion.

## Features
- Real-time facial emotion detection.
- Recognizes seven different emotions.
- Recommends music based on detected emotions.
- Uses a deep learning model for emotion classification.
- Web-based application developed using Flask.

## Technologies Used
- **Programming:** Python
- **Backend:** Flask
- **AI/ML:** TensorFlow, CNN, OpenCV
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Dataset:** FER2013

## Project Structure
- `app.py` – Main Flask application
- `camera.py` – Camera handling and emotion detection
- `utils.py` – Utility functions
- `train.py` – Model training
- `model.h5` – Trained emotion recognition model
- `requirements.txt` – Project dependencies

## Installation and Setup

1. Clone the repository:
   `git clone https://github.com/kavanabn/music-recommendation-with-emotion-recognition.git`

2. Navigate to the project folder:
   `cd music-recommendation-with-emotion-recognition`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the application:
   `python app.py`

5. Open the local URL displayed in the terminal.

## Project Outcome
The application identifies facial emotions and recommends music according to the predicted emotion.
